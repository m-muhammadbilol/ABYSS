# ABYSS — Journey Into the Unknown

An interactive ocean exploration website: depth gauge, five ocean zones, depth slider, marine life explorer, expedition builder and a knowledge quiz.

Single-file site (`index.html`), no build step, no dependencies.

## Run locally
Open `index.html` in a browser.

## Deploy
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
